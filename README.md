# Kolawole Moyosore — Portfolio

Responsive single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Deploy
Upload this folder to GitHub and enable GitHub Pages, or import the repository into Netlify or Vercel as a static site.

## Verify before publishing
- Confirm each project repository and live URL is public and correct.
- Confirm the LinkedIn profile URL.
- Check internship start dates, descriptions and current status.
- Confirm the AltSchool programme dates.
- Add any missing project-specific demos, screenshots or detailed READMEs.

Google Fonts are loaded from Google Fonts; system fallbacks are included.
